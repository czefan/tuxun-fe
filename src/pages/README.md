# 主包页面 (`src/pages`)

本目录仅存放小程序主包（TabBar 底部导航直属）核心入口页面。

---

## 📌 主包页面收录范围

- `index/`：首页 / 地图探索
- `activity/`：活动专区
- `notice/`：通知消息中心
- `my/`：个人中心首页

---

## ⚠️ 主包体积约束 (2MB 隔离)

1. **体积敏感**：微信小程序对主包体积有严苛的 2MB 上限限制。
2. **禁止放二级页**：所有非 TabBar 直属的二级详情页（如活动详情、题目答题、个人设置等）必须放入 `src/subPages/`。
3. **禁止静态跨包引用**：主包代码严禁静态 `import` 分包专属代码，防止分包被编译打入主包。
