# 通用工具函数 (`src/utils`)

本目录存放纯无状态工具函数。

---

## 📌 核心工具函数收录

- **`image-compress.ts`**：智能按需图片压缩（≤10MB 原图直传、>10MB 二分质量档位压缩、单边超限等比缩放、H5 Canvas 兜底与宽高比合法性校验）。
- **`image-preview.ts`**：跨端统一全屏大图预览调用封装。
- **`debounce.ts` / `throttle.ts`**：输入防抖与高频事件节流函数。
- **`format-count.ts`**：计数数字紧凑格式化（如 1.2k、10w）。
- **`date.ts`**：服务端时间对齐、格式化与相对时间展示。
- **`rich-text.ts`**：富文本 HTML 安全净化与格式标准化。

---

## ⚠️ 编写约束

1. **纯函数**：所有工具必须为无副作用的纯函数（Pure Functions），便于单元测试覆盖。
2. **严禁依赖 UI / Vue 实例**：不得包含 `ref`、`reactive` 或 Vue 生命周期钩子。
3. **业务工具下沉**：有具体业务语义的逻辑应放入对应 `src/features/*` 业务域中。
